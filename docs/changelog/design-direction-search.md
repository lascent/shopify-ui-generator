# Release 35 — Smart Design Direction Search

## UI change
The fixed category chips below the Design Direction input were removed. They consumed space and made the panel feel like a static preset selector.

## Smarter matching
As the user types, the field now searches:
- dedicated niche profiles
- dynamic niche categories
- the full prompt-ready category catalog
- category aliases
- design-style intent words

The top category match also produces smart design-direction variants such as Modern, Premium, Minimal, Editorial, Cinematic, Conversion-focused, Motion-led, and Bold.

## Result
The Design Direction area now behaves more like a professional intelligent search/autocomplete field instead of a fixed list of buttons.
