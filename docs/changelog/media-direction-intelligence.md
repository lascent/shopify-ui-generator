# Release 33 — Smart Media Accuracy and Design Direction Upgrade

## Added
- More images and broader candidate coverage for each category.
- More niche-aware image routing for direct searches such as laptops, jewelry, pets, coffee & tea, and books/stationery.
- Expanded Shopify category taxonomy with more prompt-ready categories and keywords.
- Smarter design-direction parsing with additional prompt signals such as cinematic intent, merch-heavy storefronts and niche-specific detection.

## Result
This update makes the generator more accurate when users type direct category requests, improves image relevance, and makes the design-direction layer better at choosing appropriate layouts and commerce structures.
