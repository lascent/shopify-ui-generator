# Release 34 — Product Layout Diversity + Modern Pricing Motion

## Added
- 5 new product layout renderers with more varied positioning and hierarchy.
- Animated moving-text / marquee strips for more modern storefront sections.
- More expressive pricing UI for strong price callouts and modern commerce styling.
- Generator hooks that respond to prompts like `unique product layout`, `moving text`, and `modern pricing`.

## Goal
Make generated storefronts feel less repetitive by giving products more distinct placement, bolder pricing treatment, and motion-led visual storytelling.
