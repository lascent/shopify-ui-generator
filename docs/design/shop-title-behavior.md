# Shop Title Behavior

- Project folder renamed to `shopify-generator`.
- Added a dedicated **Shop title** textbox to the Generate workspace.
- The value is applied when **Generate new direction** is pressed.
- Brand text updates across headers, footers, hero/brand treatments, generated design metadata and history.
- Restoring a previous generation restores its shop title into the textbox.
- Shop titles are trimmed, repeated whitespace is normalized, and input is limited to 48 characters.
